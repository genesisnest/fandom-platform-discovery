# service-understanding

Discovery Track 00 결과물을 모으는 폴더입니다. 문서는 성격에 따라 아래 4개 폴더로 나눕니다.

| 폴더 | 담는 문서 |
| --- | --- |
| `intent/` | 서비스 의도·전략을 가늠하는 문서 |
| `service-analysis/` | 실제 HI& 서비스(또는 POC)를 살펴보고 화면·기능을 정리한 문서 |
| `user-scenarios/` | 담당 영역별로 뽑은 사용자 Story·시나리오 |
| `requirements-coverage/` | 요구사항 원본과 그 분석, 요구사항 대비 검증 범위, 테스트 환경·기록 |

## 파일 이름 규칙

```
YYYYMMDD-주제-작성자.md
```

- `YYYYMMDD`: 문서를 작성한 날짜
- `주제`: 영문 kebab-case로 짧게 (예: `dm-scenario`, `feature-map`)
- `작성자`: git 계정 기준 로마자 이름

민감한 정보(테스트 계정 등)를 담은 문서는 `.local.md`처럼 구분되는 접미사를 유지하고, 내용을 원격 저장소에 올려도 되는지 먼저 확인하세요.

새 문서를 추가할 때는 위 4개 폴더 중 가장 가까운 곳에 이 규칙으로 이름을 붙여 넣어 주세요. 어느 폴더에도 맞지 않으면 팀과 상의해 새 폴더를 만듭니다.
