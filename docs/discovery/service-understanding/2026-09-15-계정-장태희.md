## 1. 비로그인

### 비로그인 접근 정책

- 비로그인 상태에서도 서비스의 주요 화면 및 콘텐츠 조회 가능
- 로그인이 필요한 기능을 수행하는 시점에 로그인 유도 팝업 노출
- 로그인 유도 팝업에서 아래 동작 제공
  - `닫기`: 현재 화면 유지
  - `로그인`: 로그인 화면으로 이동

#### 로그인 필요 기능

- 댓글/리액션 작성
- 이모티콘 관련 기능
- 상품 구매 등
- 각 기능 스토리에서 별도 분석

### 1.1 MY

#### 화면

- 경로: `/my`
- 비로그인 상태에서도 접근 가능
- 로그인 영역 노출

#### 메뉴

- 멤버십 가입하기
- 언어
- 통화
- 이용약관
- 고객센터
- 이벤트
- 공지사항

#### 인증 관련 동작

- `로그인` 선택 시 로그인 화면으로 이동
- `멤버십 가입하기` 선택 시 로그인 요구 없이 특정 아티스트 멤버십 상세 화면으로 이동

---

### 1.2 로그인

#### 진입

- MY → 로그인
- 로그인 필요 기능 → 로그인 유도 팝업 → 로그인
- 경로: `/login`

#### 플로우

1. 이메일 입력
2. 비밀번호 입력
3. `로그인` 선택
4. 로그인 처리

#### 입력 및 동작

- 이메일 형식 검증
  - 잘못된 형식 입력 시 입력 영역 오류 표시
  - `이메일 형식이 올바른지 확인해주세요.` 메시지 노출
- 비밀번호 표시/숨김 지원
- `로그인 상태 유지` 선택 가능

---

### 1.3 비밀번호 재설정

#### 진입

- 로그인 → `비밀번호를 잊으셨나요?`
- 경로: `/login/v2/reset-password`

#### 플로우

1. 이메일 입력
2. 이메일로 `인증 코드 보내기` 선택

---

### 1.4 이메일 회원가입

#### 진입

- 경로: `/signup/v2`
- 로그인 → `이메일로 가입하기` → 회원가입

#### 플로우

이메일 인증 → 회원 정보 입력 → 약관 동의 → 가입

#### 이메일 인증

- 이메일 입력
- `인증 코드 보내기`
- 인증번호 6자리 입력
- `인증하기`
- 인증 코드 `다시 보내기` 지원

#### 회원 정보 입력

- 비밀번호
- 비밀번호 확인
- 닉네임 (필수)
- 이름 (필수)
- 전화번호 (필수)
  - 국가번호 선택
- 생년월일 (필수)
- 성별 (필수)
- 비밀번호 표시/숨김 지원

#### 약관 동의

- 모두 동의
- [필수] 연령 동의
  - 대한민국: 만 14세 이상
  - 외국 국적: 만 16세 이상
- [필수] 이용약관
- [필수] 개인정보 수집 및 이용 동의
- [선택] 광고성 정보 수신 동의

#### 입력 검증

- 필수 회원 정보를 입력하지 않고 가입 시도 시 각 입력 항목에 오류 표시
  - 비밀번호
  - 비밀번호 확인
  - 닉네임
  - 이름
  - 전화번호
  - 생년월일
- 미입력 항목에 `필수 입력 항목이에요.` 메시지 노출

#### 가입

- `가입하기` 선택

## 2. 로그인 완료

### 로그인 후 이동

- 로그인 성공 시 MY(`/my`) 화면으로 이동
- 로그인 유도 팝업이 노출된 화면과 관계없이 로그인 성공 후 MY(`/my`)로 이동
- 로그인 이전 화면으로 복귀하지 않음

### 로그인 상태 관리

- 브라우저 쿠키 삭제 후 새로고침 시 로그인 상태 해제
- 로그인 상태 유지에 쿠키가 사용되는 것으로 확인

### 2.1 MY

#### 화면

- 경로: `/my`
- 로그인 사용자 정보 노출
  - 프로필 이미지
  - 닉네임
  - 이메일
  - 이용권/티켓
  - Point

#### 메뉴

- 멤버십 가입하기
- 주문/결제 내역
- 내가 쓴 글
- 내 정보 관리
- 내 리워드
- 언어
- 통화
- 알림 설정
- 이용약관
- 고객센터
- 이벤트
- 공지사항
- 로그아웃

#### 비로그인 상태와의 차이

- 로그인 영역 대신 사용자 정보 노출
- 로그인 사용자 전용 메뉴 추가 노출
  - 주문/결제 내역
  - 내가 쓴 글
  - 내 정보 관리
  - 내 리워드
  - 알림 설정
  - 로그아웃

---

### 2.2 내 정보 관리

#### 진입

- MY → `내 정보 관리`
- 경로: `/my/info`

#### 화면

- 사용자 프로필 정보 노출
  - 프로필 이미지
  - 닉네임
  - 이메일

#### 메뉴

- 프로필 수정
- 비밀번호 변경
- 회원정보 변경
- 로그인 관리
- 회원 탈퇴

---

### 2.3 프로필 수정

#### 진입

- 내 정보 관리 → `프로필 수정`
- 경로: `/my/profile`

#### 수정 항목

- 프로필 이미지
  - 프로필 이미지 선택 시 파일 선택 창 노출
- 닉네임 (필수)
- 닉네임 미입력 상태에서는 `저장하기` 비활성화

#### 동작

- `저장하기` 선택 시 변경된 프로필 정보 저장

---

### 2.4 비밀번호 변경

#### 진입

- 내 정보 관리 → `비밀번호 변경`
- 경로: `/my/change-password`

#### 입력 항목

- 현재 비밀번호
- 새 비밀번호
- 비밀번호 확인
- 각 비밀번호 입력 항목 표시/숨김 지원

#### 동작

- `비밀번호 변경` 선택 시 비밀번호 변경

---

### 2.5 회원정보 변경

#### 진입

- 내 정보 관리 → `회원정보 변경`
- 경로: `/my/detail`

#### 수정 항목

- 이름 (필수)
- 전화번호 (필수)
  - 국가번호 선택
- 생년월일 (필수)
- 성별 (필수)

#### 동작

- 기존 회원정보가 입력된 상태로 노출
- `수정하기` 선택 시 회원정보 변경

---

### 2.6 로그인 관리

#### 진입

- 내 정보 관리 → `로그인 관리`
- 경로: `/my/session-manager`

#### 기능

- 현재 사용 중인 기기를 제외한 다른 기기에서 로그아웃 가능
- `모든 기기에서 로그아웃` 기능 제공
- 다른 기기에서 로그아웃하더라도 연결된 서비스는 계속 이용 가능하다고 안내
- 현재 사용 중인 기기 외 로그인된 기기가 없는 상태
  - 현재 사용 중인 기기 외 로그인한 기기가 없어요.` 토스트 메시지 노출

---

### 2.7 회원 탈퇴

#### 진입

- 내 정보 관리 → `회원 탈퇴`
- 경로: `/my/withdraw`

#### 유의사항

- 탈퇴 후에도 기존에 등록한 콘텐츠와 댓글은 삭제되지 않음
- 삭제가 필요한 콘텐츠는 탈퇴 전에 직접 삭제 필요
- 남은 이용권, 멤버십 혜택, 포인트는 소멸되며 복구 불가
- 배송이 완료되지 않은 주문은 정상 배송되지만 서비스 내 배송 조회 불가
- 회원 탈퇴 시 회원정보는 삭제되며 복구 불가
- 법령 또는 회사 내부 정책에 따라 일부 정보는 일정 기간 보관될 수 있음

#### 동작

- 유의사항 확인 동의 제공
- 동의 후 `탈퇴하기` 가능
- `취소` 제공

### 2.8 로그아웃

#### 진입

- MY → `로그아웃`

#### 플로우

로그아웃 선택 → 로그아웃 확인 팝업 → 로그아웃 → 비로그인 MY(`/my`)

#### 동작

- `로그아웃` 선택 시 `로그아웃 할까요?` 확인 팝업 노출
- 확인 팝업에서 아래 동작 제공
  - `취소`: 팝업 닫기
  - `로그아웃`: 로그아웃 처리
- 로그아웃 완료 후 MY(`/my`) 화면 유지
- 사용자 정보 및 로그인 사용자 전용 메뉴가 제거되고 비로그인 MY 화면 노출
