# Track 00 — Home 기준 페이지 구조·기능 리포트

## 읽는 기준

2026-09-14에 수행한 [POC 웹 스토리 테스트 52개 기록](./track-00-web-test-report.md)을 **페이지 중심으로 재분류**한 두 번째 리포트다. 새 화면 테스트를 수행한 결과가 아니며, 대상은 `https://poc-hiand.bstage.in/`의 데스크톱 웹이다.

- 아래 트리는 Home을 출발점으로 한 **메뉴·탐색 구조**다. URL의 실제 부모/자식 구조나 모든 페이지 간 이동을 뜻하지 않는다.
- `[탭]`, `[팝업]`, `[편집기]`는 페이지 안에서 파생되는 화면이다. 별도 페이지로 중복 집계하지 않는다.
- `→`는 기존 테스트에서 확인한 연결이다. 여러 곳에서 사용하는 콘텐츠 상세·상품 상세·주문서 등은 공통 화면으로 본다.
- 기능 표의 **동작 확인**은 적힌 동작만 실행했다는 뜻이다. **화면 확인**은 표시·안내·입력 UI만 관찰한 것이며 저장·발행·결제 성공을 뜻하지 않는다. **빈 상태**, **접근 제한**, **진입 미확인**도 구분한다.
- `W-xx`는 [기존 테스트 리포트](./track-00-web-test-report.md)의 근거 ID다. 기획 행별 판정은 [원본 요구사항별 검증 범위](./track-00-requirement-coverage.md)를 유지한다.
- 계정 식별자·비밀번호·개인 주문번호는 기재하지 않는다. 개발 서버·앱·어드민 테스트는 포함하지 않는다.

### 2.2 아티스트 라운지 — Story·Contents·Community

대상 경로는 `/lounge/parkseojun/...`이지만 실제 표시 데이터는 **KIM BAE WOO / 김배우**였다. 경로명과 아티스트 표시가 일치한다고 가정하지 않는다.

| 페이지·파생 화면 | 주요 기능 | 확인 결과·남은 조건 | 근거 |
| --- | --- | --- | --- |

| 비로그인 → 공개 라운지·공개 포스트 | 공개 읽기 가능, 입장·댓글·공감은 로그인 안내 | 공개 브라우저 접근과 앱 전체 로그인 게이트는 별도다. |
| 로그인 → 무료 라운지 입장 → 글쓰기/댓글 편집기 | 무료 입장 후 글쓰기와 댓글 입력 UI 확인 | 실제 발행 권한 전체는 미검증이다. 댓글/공감에 라운지 가입이 필수인지도 조건별로 분리 검증하지 않았다. |
| 무료 라운지 가입 → 멤버십 전용 포스트 | 본문·댓글 제한 유지 | 무료 라운지 가입이 해당 멤버십 권한을 대체하지 않는 사례다. |
| 로그인·기존 DM 보유 → 채팅 카드 | 모바일 앱 설치 안내 | 웹 소개/구매/이용권 관리와 실제 채팅 이용을 구분해야 한다. |
| 멤버십 미보유 → KIT 바로 구매 | 멤버십 회원만 구매 가능 안내 | 미보유 제한만 확인했으며 보유 회원 성공은 미검증이다. |
| 상품 옵션 → 장바구니/주문서 | 상품 유형별 입력 UI, 최종 동의·결제는 미실행 | 옵션 선택·주문서 진입을 구매 성공으로 처리하지 않는다. |
| 알림함 → 일정 → 월 그리드 | 공통 스케줄로 이동·일정 조회 | 스케줄은 확인됐지만 라운지 헤더의 캘린더 진입은 미확인이다. |
| 이용권 → 기존 주문 → 스타 변경 | 웹 변경 화면 존재, 선택·저장 미실행 | 기존 웹 변경 경로와 목표 앱 슬롯 설계는 별도다. |

## 4. 페이지 기준으로 남은 확인 항목

| 분류 | 대상 | 다음 검증에 필요한 조건 |
| --- | --- | --- |
| 진입 미확인 | 스티커·테마·쿠폰·하이페이·통합 ID QR·내 VOD·이벤트 내역, 라운지 검색/필모그래피/캘린더 진입 | 실제 메뉴·웹/앱 적용 범위 확인. 웹에서 못 찾았다는 이유만으로 미구현으로 단정하지 않는다. |
| 진입점만 확인 | 비밀번호 변경, 포스트 링크 복사/신고/차단, 라운지 나가기, 세션 종료, 외부 캘린더 추가/공유 | 목적지와 실제 실행 범위를 별도로 확인한다. 현재 도식의 메뉴 표시가 실행 성공을 뜻하지 않는다. |
| UI만 확인 | 글/댓글 발행·업로드·프로필 저장·알림 변경·스타 변경 | 테스트 내용·파일·대상과 변경/복구 범위를 정한 뒤 진행한다. |
| 데이터 부족 | 이벤트·리워드·취소/배송/멤버십 주문·작성글/문의·포인트 적립/차감 | 해당 데이터를 준비해 상세·후속 동작을 검증한다. |
| 권한 조합 부족 | 멤버십/해당 아티스트 DM/둘 다/비보유, 비밀보드 작성자·아티스트·관리자 | 조건별 계정·콘텐츠를 준비해 접근 결과를 비교한다. |
| 구매 완료 미실행 | 결제·갱신·중복 구매·기간 연장·환불·주소 저장·배송비·쿠폰/포인트 실사용 | 허용 상품·금액·테스트 결제수단·정기결제 허용 여부를 정해야 한다. 0원 상품도 예외로 구매하지 않았다. |
| 별도 플랫폼·운영 범위 | 모바일 앱 채팅/슬롯/VOD·아티스트 앱·어드민·예약·비기능 | 별도 환경·권한·테스트 데이터·측정 기준이 필요하다. |

현재 문서는 **관찰된 POC의 페이지 지도**다. 기획의 목표 페이지 구조로 확정하려면 아티스트/상품 fixture 매핑, 소개 링크, 약관·FAQ 내용, 플랫폼별 메뉴 차이를 먼저 정리해야 한다.
