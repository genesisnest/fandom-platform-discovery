# 하이앤드 웹 사용자 시나리오 — 박서준 라운지

2026.09.14 · PC Chrome · 한국어 · 비로그인

박서준의 소식을 보러 온 팬의 입장에서 하이앤드 웹을 둘러봤다. 라운지를 찾고, 콘텐츠와 팬들의 글을 읽고, 입장이나 댓글 작성을 시도했을 때 어떤 흐름으로 이어지는지 정리했다.

## 1. 박서준의 라운지를 찾아 들어간다

박서준의 소식이 어디에 모여 있는지 찾기 위해 홈에서 아티스트 목록을 확인한다.

**이동 경로:** HOME → LINE-UP → 박서준 선택

박서준을 선택하면 라운지가 새 창으로 열린다. 로그인하지 않은 상태에서도 라운지 화면을 볼 수 있다.

라운지에 접속하는 것과 화면 하단의 **‘입장하기’** 버튼을 누르는 것은 별도의 행동이었다.

## 2. 라운지에 입장하려고 한다

라운지를 둘러보다 화면 하단의 **‘입장하기’** 버튼을 누른다.

**이동 경로:** 라운지 → 입장하기 → 로그인 안내

‘로그인이 필요해요’ 안내창이 뜨고, ‘취소’와 ‘로그인’ 버튼이 표시된다.

| 선택 | 결과 |
| --- | --- |
| 취소 | 안내창이 닫히고 라운지 화면은 그대로 유지된다. |
| 로그인 | 로그인 화면으로 이동한다. |

비로그인 상태에서는 이 단계에서 로그인을 요구한다. 로그인 후 바로 입장되는지, 추가 절차가 있는지는 다음에 확인할 예정이다.

[이동한 로그인 화면](https://hiand.com/login)

## 3. Contents에서 관심 있는 소식을 읽는다

박서준의 작품이나 활동 소식을 찾아보기 위해 Contents 탭을 선택한다.

**이동 경로:** Contents → PORTFOLIO → 콘텐츠 선택 → 상세페이지

Contents는 **PORTFOLIO, EVENT, HI-LIGHT, VIDEO**로 나뉘어 있다. 각 섹션에는 썸네일과 제목이 캐러셀 형태로 배치되어 있다.

PORTFOLIO에서 **[ON SCREEN] ‘경도를 기다리며’ 2025.12.06 첫 방송**을 선택했다. 콘텐츠 상세페이지로 이동했고, 본문과 댓글을 모두 볼 수 있었다. 이 콘텐츠를 읽는 동안 로그인이나 이용권 안내는 나오지 않았다.

[확인한 콘텐츠](https://hiand.com/contents/69310b79c15b7f6b406acc77)

## 4. Community에서 다른 팬들의 글을 읽는다

같은 배우를 좋아하는 팬들이 어떤 이야기를 나누는지 보기 위해 Community로 이동한다.

**이동 경로:** Community → 게시판 선택 → 글 목록 → 글 상세

왼쪽에는 **TO. SEO JUN, SEO JUN FAN ART, Music, FREE TALK, NOTICE** 메뉴가 있다. 각 메뉴를 누르면 해당 게시판의 글들이 표시된다.

TO. SEO JUN의 글 하나를 선택하니 커뮤니티 글 상세페이지로 이동했다. 비로그인 상태에서도 댓글을 읽을 수 있었다.

[확인한 커뮤니티 글](https://hiand.com/community/board/671f24213c40f64e4c19fbbf/post/6aa7470fe22f4673b05a1300)

## 5. 읽던 글에 댓글을 남기려고 한다

글과 댓글을 읽은 뒤, 대화에 참여하기 위해 댓글 작성 위치를 확인한다.

**이동 경로:** 커뮤니티 글 상세 → 댓글 작성 진입

댓글을 작성하려는 위치에는 **‘로그인이 필요해요’**라는 안내가 표시되어 있다. 안내를 누르면 안내창이 뜬다.

댓글을 읽을 때는 로그인 요구가 없었지만, 작성하려는 단계에서는 로그인을 요구했다. 로그인만 하면 작성할 수 있는지, 라운지 입장까지 필요한지는 아직 확인하지 않았다.

## 이번 탐색에서 확인한 점

| 사용자 행동 | 비로그인 상태에서 확인한 결과 |
| --- | --- |
| 박서준 라운지 방문 | 가능 |
| 선택한 Contents 콘텐츠의 본문·댓글 읽기 | 가능 |
| Community 게시판 탐색·선택한 글 상세와 댓글 읽기 | 가능 |
| 라운지 입장하기 | 로그인 요구 |
| Community 댓글 작성 진입 | 로그인 요구 |

이번에 읽은 콘텐츠와 커뮤니티 글은 로그인 없이 확인할 수 있었다. 라운지에 입장하거나 댓글을 작성하려는 시점에 로그인 안내가 나왔다. 다른 콘텐츠에도 같은 공개 범위가 적용되는지는 추가 확인이 필요하다.

## 다음 확인

- 로그인 후에도 라운지의 ‘입장하기’가 별도로 필요한가?
- 입장하기를 누르면 추가로 입력하거나 동의해야 하는 내용이 있는가?
- 로그인만 한 상태와 라운지 입장을 완료한 상태에서 댓글 작성 조건이 달라지는가?

로그인과 라운지 입장을 나누어 진행하면서 같은 커뮤니티 글에서 비교할 예정이다.
