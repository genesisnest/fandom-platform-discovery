# Track 00 — 요구사항별 웹 검증 범위

## 기준

- 기준일: 2026-09-14. 원본: [01. 요구사항_v1.00.xlsx](./01.%20요구사항_v1.00.xlsx).
- 실행 근거: [POC 웹 스토리 테스트 기록](./20260915-poc-web-test-log-shinhaeng.md)의 W-01~W-52. 1차 비로그인·2차 회원의 해당 ID 행동/결과만 실제 실행했다.
- 기능·정책 시트 335행(2~336행), 비기능 16행(3~18행), 참고 알림 8행(3~10행), 합계 359행을 빠짐없이 검토했다.
- 기능명 C열이 빈 90행(팬 차단)과 196행(단일 유형 상품 상세)도 B/D열 내용에 따라 포함했다. 이전 333건 집계는 C열이 있는 행만 센 값이다.
- **7행의 좁은 동작 확인, 105행의 부분 확인, 나머지 247행은 조건·권한·플랫폼 때문에 미실행/별도 검증으로 분류했다. 이는 359건 전체 테스트 통과가 아니다.**
- ‘부분 확인’은 화면 노출이나 비로그인 제한까지만 확인했다는 뜻이다. ‘웹 진입 미확인’은 이번 대상 화면에서 찾지 못했다는 뜻이며 미구현 확정이 아니다.
- 사용자 주소 확인 후 로그인·무료 라운지 가입에 성공했다. 계정 정보는 기재하지 않는다. 구매·회원/라운지 탈퇴·약관 수락·공개 작성은 미실행이다. 이번에 추가한 장바구니 항목·하트 반응만 원상복구했다.
- 행 번호는 원본 Excel 번호다. 원문 기능명·상세는 추적용이며 기획서의 정책 문구를 서비스 동작이나 법률 판단으로 확정한 것이 아니다.
