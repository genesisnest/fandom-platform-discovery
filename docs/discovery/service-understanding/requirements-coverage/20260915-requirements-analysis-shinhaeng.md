## 서비스 한 문장

팬은 라운지에서 아티스트와 콘텐츠를 발견하고, DM 구독·멤버십·상품 구매를 통해 관계와 혜택을 넓힌다. 아티스트와 운영자는 이를 발신·운영하며, 어드민은 권한, 결제, 콘텐츠 공개, 현장 수령을 통제한다.

## 공통 도메인

| 개념 | 기획서에서의 의미 | 설계 시 기준 |
| --- | --- | --- |
| 계정 | 팬의 통합 ID. SSO, 이메일 인증, 프로필, 설정, 구매 이력을 가진다. | 팬 계정과 아티스트 계정은 분리된다. |
| 라운지 | 팬이 스토리·콘텐츠·커뮤니티·샵을 이용하는 공간이다. 가입은 무료이며 DM·멤버십과 별개다. | 라운지 가입 여부를 독립 상태로 둔다. |
| 그룹 | 멤버십, 할인, 스티커 노출, 콘텐츠 권한의 기준이 되는 아티스트 묶음이다. | 라운지 및 아티스트와의 관계 규칙을 확정해야 한다. |
| DM 구독 | 특정 아티스트와의 유료 메시지 관계다. 앱 슬롯형과 웹 아티스트 구독형이 다르다. | 상품·결제 경로와 별개로 권한 및 기념일을 관리한다. |
| 멤버십 | 그룹 단위로 판매하는 권한 상품이다. | `사용자 × 그룹` 보유 상태가 콘텐츠·커뮤니티·상품 권한에 쓰인다. |
| 콘텐츠 | 스토리, 미디어, 라이브 다시보기, VOD를 포괄한다. | 공개 조건은 멤버십과 DM 구독을 함께 판정한다. |
| 리워드 | 음성·사진·영상 등 수신자 전용 디지털 혜택이다. | URL만으로 재생할 수 없어야 한다. |

## 핵심 사용자 상태

```text
비로그인
  → 팬 계정
    → 라운지 가입
    → DM 구독(아티스트 단위)
    → 멤버십 보유(그룹 단위)
    → 상품·이벤트·리워드 권한
```

- 라운지 가입, DM 구독, 멤버십 보유는 서로 대체하지 않는다.
- 콘텐츠 권한은 멤버십·DM 구독의 `멤버십만 / DM만 / OR / AND` 조건으로 판정한다.
- 구독 만료 뒤 DM은 읽기 전용으로 전환하고, 구매 기간의 과거 메시지는 계속 읽을 수 있다는 요구가 있다.
- 시간 데이터는 UTC 절대 시각으로 저장하고, 사용자 지역 시각과 기준 시간대를 함께 표시한다. 종일 일정은 변환하지 않는다.

## 기존 조사 문서와 연결

- 공개 웹에서 확인한 `라운지 방문 → 콘텐츠/커뮤니티 읽기 → 로그인 → 라운지 입장 → 작성` 흐름은 [HI& 주요 기능 지도](../service-analysis/20260914-feature-map-jisu.md)와 [박서준 라운지 비로그인 탐색 기록](../service-analysis/20260914-guest-scenario-lounge-seongbin.md)에 있다.
- 기획서는 모바일 앱을 중심으로 DM·라이브·현장 수령·어드민까지 훨씬 넓은 목표 범위를 정의한다.
- 따라서 Track 00에서는 웹의 현재 동작을 목표 정책으로 오해하지 않고, 각 항목을 `AS-IS`, `TO-BE`, `미정`으로 구분해 논의해야 한다.
