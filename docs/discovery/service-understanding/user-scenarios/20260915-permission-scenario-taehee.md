# 권한

<br>

## 1. 로그인 권한

### 비로그인

- 서비스 주요 콘텐츠 조회 가능
- 로그인 필요 기능 이용 시 로그인 유도

### 로그인

- 로그인 사용자 전용 기능 이용 가능

<br>

## 2. 이용권 / 멤버십 권한

### DM 이용권

#### 미보유

- 해당 스타의 DM 이용권 구매 화면 제공
- DM 이용을 위해 이용권 구매 필요
- 이용권 상품 선택 및 구매 가능

#### 보유

- 이용권을 구매한 스타의 DM 이용 가능
- 스타에게 메시지 전송 가능

### 멤버십

#### 미가입

- 일반 콘텐츠 조회 가능
- 멤버십 전용 콘텐츠 접근 제한

#### 가입

- 해당 멤버십의 전용 콘텐츠 조회 가능
- 멤버십 전용 콘텐츠에 `멤버십` 표시 노출

<br>

## 3. 사용자 역할 권한

### 팬

- Lounge 이용
- DM 이용권 보유 시 해당 스타와 DM 이용 가능
- 멤버십 보유 시 멤버십 전용 콘텐츠 이용 가능

### 스타

- 팬에게 메시지 전송 가능
- 라이브 시작 가능
  - 채팅
  - 영상
- Story 작성 가능
- 스타 활동 현황 확인 가능
  - 팬에게 보낸 메시지 개수
  - 라이브 진행 시간
  - 출석 횟수
