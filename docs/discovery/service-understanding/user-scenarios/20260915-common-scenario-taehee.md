# 공통 기능

<br>

## 1. GNB

### 노출

- 서비스 주요 화면에서 공통 노출

### 메뉴

- HOME
- LINE-UP
- DM
- SHOP
- 알림
- 장바구니
- MY

### 동작

- 각 메뉴 선택 시 해당 페이지로 이동
- 로그인/비로그인 상태에 따른 GNB 메뉴 구성 차이 없음

<br>

## 2. 공통 설정

### 2.1 언어 설정

#### 진입

- MY → `언어`
- 경로: `/my/language`
- 비로그인 상태에서도 접근 가능

#### 지원 언어

- 한국어
- 영어
- 일본어
- 중국어 간체
- 중국어 번체
- 스페인어

#### 동작

- 현재 설정된 언어에 선택 표시
- 언어 선택 시 기본 언어 변경
- 변경 완료 시 토스트 메시지 노출
  - 예: `기본 언어를 한국어로 변경했어요`

---

### 2.2 통화 설정

#### 진입

- MY → `통화`
- 경로: `/my/currency`
- 비로그인 상태에서도 접근 가능

#### 지원 통화

- JPY - 일본 ¥(엔)
- KRW - 한국 ₩(원)
- USD - 미국 $(달러)

#### 동작

- 현재 설정된 통화에 선택 표시
- 통화 선택 시 기본 통화 변경
- 변경 완료 시 토스트 메시지 노출
  - `기본 통화를 변경했어요`

---

### 2.3 이용약관

#### 진입

- MY → `이용약관`
- 경로: `/terms`
- 비로그인 상태에서도 접근 가능

#### 항목

- 이용약관
- 개인정보 수집 및 이용 동의
- 개인정보처리방침
- 청소년 보호정책
- 광고성 정보 수신 동의
- 커뮤니티 이용 가이드

#### 상세 조회

- 각 항목 선택 시 해당 약관/정책 상세 화면으로 이동
- 상세 화면에서 약관/정책 내용 노출
- 시행일 선택 기능 제공
- 시행일 선택 시 해당 버전의 약관/정책 내용 조회 가능

---

### 2.4 고객센터

#### 진입

- MY → `고객센터`
- 경로: `/cs`
- 비로그인 상태에서도 접근 가능

#### 메뉴

- 내 문의 내역
- FAQ

#### 내 문의 내역

- 경로: `/cs/user-inquiry`
- 로그인 사용자만 이용 가능
- 비로그인 상태에서 선택 시 로그인 필요 팝업 노출
- 로그인 상태에서 등록한 문의 내역 조회 가능
- 문의 내역이 없는 경우 `문의한 내용이 없어요` 문구 노출

#### FAQ

- 경로: `/cs/faq`
- 비로그인 상태에서도 접근 가능
- 카테고리별 FAQ 제공
- 질문 선택 시 해당 답변 영역 펼침/접힘
- 답변 내 관련 기능으로 이동할 수 있는 링크 제공
- FAQ에서 해결되지 않은 경우 `직접 문의하기` 기능 제공

##### 가이드 콘텐츠

- FAQ에서 서비스 이용 가이드 제공
  - 예: `LOUNGE GUIDE`
  - 예: `DM GUIDE`
  - 예: `앱 다운로드 가이드`
- 가이드 선택 시 별도 콘텐츠 상세 화면으로 이동
- 비로그인 상태에서도 조회 가능

#### 직접 문의하기

- 로그인 사용자만 이용 가능
- 비로그인 상태에서 선택 시 로그인 유도 팝업 노출
- 로그인 상태에서 문의 작성 화면으로 이동

##### 입력 항목

- 문의 유형
- 문의 내용
- 사진 첨부
  - 최대 10장

#### 로그인 필요 동작

- 고객센터 및 FAQ 조회는 비로그인 상태에서도 가능
- 아래 기능은 로그인 필요
  - 내 문의 내역 조회
  - 직접 문의하기
  - FAQ 답변에서 로그인 필요 기능으로 이동
- 로그인 필요 기능 선택 시 로그인 유도 팝업 노출

---

### 2.5 이벤트

#### 진입

- MY → `이벤트`
- 경로: `/event`
- 비로그인 상태에서도 접근 가능

#### 구분

- 진행중
- 종료됨

#### 동작

- `진행중` 선택 시 진행 중인 이벤트 목록 조회
- `종료됨` 선택 시 종료된 이벤트 목록 조회
- 선택된 탭에 활성 상태 표시

#### Empty State

- 조회되는 이벤트가 없는 경우 `등록된 이벤트가 없어요` 문구 노출

---

### 2.6 공지사항

#### 진입

- MY → `공지사항`
- 경로: `/notice`
- 비로그인 상태에서도 접근 가능

#### 목록

- 등록된 공지사항 목록 노출
- 각 공지사항에 아래 정보 노출
  - 제목
  - 등록일

#### 상세 조회

- 공지사항 선택 시 상세 화면으로 이동
- 경로: `/notice/{id}`
- 상세 화면에서 아래 정보 노출
  - 제목
  - 등록일
  - 본문
- 비로그인 상태에서도 조회 가능
